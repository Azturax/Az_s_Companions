# Changelog

## 0.1.0 — first public

### Gameplay
- Companion Charm (desert pyramid loot) summons / stores Kon; one charm per player
- Kon follows the owner; sleeps in Kon Bed at night (placing a Kon Bed sets home)
- Shift+right-click Customize (NeoForge); chat Q&A with canned wholesome replies
- Rename / customize / home commands

### Removed from earlier drafts
- Companion Contract, Sewing Table, Wardrobe, and sewing recipes

### Loaders
- NeoForge and Fabric jars for Minecraft 1.21.1
